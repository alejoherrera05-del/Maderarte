Ayuda con la conexión

Crear conexión en GitHub ↗. En Repository access, elige Only select repositories y selecciona únicamente Maderarte.

En GitHub, crea un token de acceso detallado limitado a tu repositorio Maderarte, con permiso Contents: Read and write. No uses la contraseña de tu cuenta de GitHub.

La conexión queda cifrada en este navegador. En otro equipo, o si borras sus datos, tendrás que configurarla de nuevo. Olvidar esta contraseña requiere volver a vincular un token autorizado.
